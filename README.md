# Реестр устройств

Простой реестр устройств, написанный на C++ с поддержкой взаимодействия с Rust через FFI.

## Возможности
- Регистрация устройств с уникальными ID.
- Хранение информации об устройствах: ID, категория и название.
- Поиск устройств по ID или индексу.
- Получение общего количества зарегистрированных устройств.
- Фиксированная вместимость — 32 устройства.
